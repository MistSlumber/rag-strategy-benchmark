# 实验设计与结论记录

## 目的

验证一个常见说法：「RAG 效果不好就加混合检索、再加一层重排」。做法是固定除排序逻辑以外的一切，逐个加上模块，看分数怎么动。

## 设置

- 语料：20 张中文知识卡，覆盖 RAG / Agent / 微调 / 评测 / 产品五个主题，全部自写。
- 评测集：20 条口语化提问，每条标注应命中的知识卡编号，包含同义改写与术语省略。
- 指标：`Recall@3`（正确片段是否进前 3）、`MRR`（第一条正确结果的位置倒数均值）。
- 检索单元：中文单字 + 相邻双字（不引入分词器，保证零依赖、结果可复现）。
- 唯一变量：排序策略。BM25 参数 k1=1.5 / b=0.75，RRF 常数 k=60，两路各取 top-10。

## 结果

| 策略 | Recall@3 | MRR | 未命中 |
| --- | --- | --- | --- |
| BM25 | 0.8500 | 0.7917 | 3 |
| TF-IDF 余弦 | 0.8500 | 0.7417 | 3 |
| RRF 混合 | 0.8500 | 0.7917 | 3 |
| 混合 + 启发式重排 | 0.7000 | 0.5833 | 6 |

## 归因

**1. 融合没收益，因为两路不互补。** BM25 与 TF-IDF 都建立在同一个 token 空间上，只是权重公式不同，top-10 名单大面积重叠。RRF 的价值在于把「一路漏掉、另一路捞到」的结果合起来；两路同质时，它只是把原来的排序重新加权一遍。

**2. 重排变差，因为判据本身错了。** 启发式重排用 query 与标题/正文的词面覆盖率打分，标题权重是正文的两倍。口语化提问里的「衡量」「瞎编」「费用」几乎不出现在正确卡的标题里，却容易在无关卡里碰巧命中，于是正确片段被挤出 top-3。这不是调权重能救的：判据缺少语义信号。

**3. 三条基线失败案例是同一类问题。** 均属同义鸿沟，词面检索从原理上无法覆盖。它们应当作为「引入语义检索」的验收目标，而不是靠特判修掉。

## 结论与下一步

在没有语义信号之前，**堆叠词面策略不产生收益，甚至互相干扰**。后续实验按这个顺序做，每步都用同一份评测集回归：

1. 接入真实 embedding 模型，做 BM25 + 向量的 RRF 融合，目标是把 3 条同义鸿沟救回至少 2 条；
2. 接入真正的 cross-encoder reranker，观察 MRR 是否提升（排序质量）；
3. 固定胜出组合，再谈分块参数与提示词优化。

## 局限

- 20 条评测集规模很小，分数波动大，结论只作方向性判断，不作性能承诺。
- TF-IDF 是稠密检索的近似，不能代表真实向量模型的表现。
- 启发式重排刻意保留为反面教材，不代表生产 reranker 的水平。
- 全部语料为自写示例，不含任何第三方教材或课程资料。
